WEBSITE PORTOFOLIO ADE NURCAHYA

CARA MENJALANKAN
1. Ekstrak file ZIP ini.
2. Buka folder Website_Portofolio_Ade_Nurcahya.
3. Klik dua kali index.html, atau buka folder dengan Visual Studio Code lalu jalankan menggunakan Live Server.
4. Pastikan koneksi internet aktif untuk memuat Google Fonts dan Font Awesome.

STRUKTUR
- index.html
- css/style.css
- js/script.js
- assets/ (gambar placeholder)

PENTING
- Ganti assets/profile-placeholder.svg dengan foto Anda (beri nama profile.jpg), lalu ubah src gambar profil di index.html menjadi assets/profile.jpg.
- Gambar proyek saat ini adalah ilustrasi placeholder. Ganti dengan gambar karya Anda dan sesuaikan src di index.html.
- Tombol CV mengarah ke tautan Google Drive yang sudah ada di file sumber. Pastikan akses tautannya publik/siapa saja yang memiliki link.
- Form kontak membuka aplikasi email (mailto), sehingga tidak mengirim pesan melalui server.
